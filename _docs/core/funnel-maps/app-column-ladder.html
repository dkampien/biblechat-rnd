App route column ladder

Counts are the nodes, rates sit on the edges, cost-pers hang off each node and all divide the same spend. Every box is an Ads Manager column, named as Ads Manager names it. The page holds no numbers of its own: it renders one reading (a pool's raw counts and its world) and computes the rest, then runs the diagnosis rules. Swap the reading and the same ladder reads another ad, ad set, or campaign. Grey cells are blank by design, not leaks.
