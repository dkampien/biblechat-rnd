Reading an ad without fooling yourself

This route pays before it installs. The ad's number is CPA on a $18.99 intro, not CPT. Do not compare it to the app route's CPT; the money shapes differ.
Two registrations per buyer. CompleteRegistration fires at email capture and again on the download click, so registration counts run high on rows with many buyers.
The pixel is 1358749622795508. The "Bible Chat Web" dataset read in Basmo IOS shows none of this; read the WEB account's dataset.
One funnel per pool. Five quiz funnels share this shape with different rates; read an ad against the funnel it sends to, never against the blend.
Modeled is not collected. M12 134% is the colleague's retention model; $180k collected on $542k is the only hard number. Say which one a decision uses.
Starvation is not a verdict. Under 100 impressions there is no read; rerun, do not kill.
