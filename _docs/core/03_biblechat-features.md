# BibleChat Features

Source: `_reference-repos/biblechat-ios` @ 63df879ef (scanned 2026-06-17). The iOS repo ships a full `docs/features/` set (38 numbered docs); this table is distilled from those docs and the feature source folders. Every row cites a real path so ad work can't drift into invented features.
